# Event Dispatch Engine UI

This is a React-based UI for the Event Dispatch Engine.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The UI will be available at http://localhost:3000

## Build

To build for production:
```bash
npm run build
```

## Components

- **Client**: Allows submitting tasks and viewing real-time updates via Server-Sent Events
- **Dashboard**: Displays request history with auto-refresh every 2 seconds
